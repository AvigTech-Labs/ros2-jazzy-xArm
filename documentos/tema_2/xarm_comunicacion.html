Práctica xArm: nodos, tópicos y mensajes

Objetivo: observar el grafo ROS 2 de xArm y crear un nodo educativo que lea posiciones articulares sin enviar comandos de movimiento.

Conceptos relacionados: Conceptos Básicos y Tutoriales.

Paso 1. Iniciar un escenario de práctica

Ejecuta uno de los escenarios descritos en Instalación de xArm ROS 2 para Jazzy. Para trabajar con un modelo sin hardware puedes comenzar con:

ros2 launch xarm_description xarm6_rviz_display.launch.py

En una nueva terminal, después de activar Jazzy y el workspace mediante ~/.bashrc, ejecuta:

ros2 node list
ros2 topic list -t
ros2 topic find sensor_msgs/msg/JointState

Importante: identifica el nombre real del tópico que publica sensor_msgs/msg/JointState. La presencia de un modelo URDF por sí sola no garantiza que un determinado tópico publique datos.

Paso 2. Inspeccionar el mensaje

En este ejemplo, sustituye /joint_states por el resultado de la inspección anterior si utiliza otro nombre:

ros2 interface show sensor_msgs/msg/JointState
ros2 topic info /joint_states -v
ros2 topic echo /joint_states --once
ros2 topic hz /joint_states

El mensaje contiene name, position, velocity y effort. Las posiciones de juntas rotativas se expresan en radianes en la convención del mensaje. Consulta los valores y verifica sus nombres: no presupongas que todas las entradas corresponden a las seis juntas del brazo (puede aparecer una pinza).

Paso 3. Crear un paquete educativo independiente

El archivo descargable de este curso contiene el proyecto ejemplos_ros2/avigtech_xarm_intro. Copia esa carpeta dentro del workspace existente sin modificar el repositorio oficial:

cp -r /RUTA/AL_CURSO/ejemplos_ros2/avigtech_xarm_intro \
    ~/ros2_ws/src/
cd ~/ros2_ws
colcon build --symlink-install --packages-select avigtech_xarm_intro
source install/setup.bash

Paso 4. Ejecutar el nodo monitor

La práctica no controla el robot. Lee mensajes JointState, publica un resumen de texto y ofrece un servicio de consulta.

ros2 launch avigtech_xarm_intro monitor_articular.launch.py \
    topic_articular:=/joint_states

El argumento topic_articular permite cambiar la fuente sin modificar el código Python. Si el tópico real es otro, utiliza ese nombre en el lanzamiento.

En otra terminal:

ros2 node info /avigtech_xarm/monitor_articular
ros2 topic echo /avigtech/xarm/resumen --once
ros2 param get /avigtech_xarm/monitor_articular topic_articular

Nota

El servicio y el tópico de resumen solo devuelven datos útiles una vez que el monitor haya recibido un JointState. Si el simulador no publica, revisa los nombres y el QoS de ambos extremos.

Comprender el fragmento de Python

El ejemplo incluido en el paquete utiliza las funciones de rclpy. El siguiente extracto muestra el concepto (la clase completa y las importaciones están en monitor_articular.py):

self.crear_suscriptor = self.create_subscription(
    JointState,
    self.topic_articular,
    self.recibir_estado,
    qos_profile_sensor_data,
)
self.publicador = self.create_publisher(
    String, '/avigtech/xarm/resumen', 10
)
self.servicio = self.create_service(
    Trigger, '/avigtech/xarm/obtener_estado', self.consultar_estado
)

  • JointState es el tipo del mensaje recibido.

  • self.recibir_estado es el callback que se ejecuta al llegar un dato.

  • qos_profile_sensor_data prioriza recibir datos recientes de sensores y puede comunicarse con publicadores de QoS fiable.

  • String identifica el tipo del tópico de resumen.

  • Trigger implementa una respuesta a una solicitud puntual.

El proyecto completo contiene package.xml, setup.py, setup.cfg y un lanzamiento ROS 2 para repetir la práctica.

Reto de programación

  1. Localiza en monitor_articular.py la función suscriptora.

  2. Explica el uso de self.create_subscription y del timer.

  3. Identifica el parámetro del nombre del tópico.

  4. Modifica el formato del resumen para mostrar posiciones en grados, sin alterar el mensaje original (que usa radianes).

  5. Compara ros2 topic hz antes y después del cambio. ¿Cambia la tasa de publicación original o solo la del resumen?

Solución del reto: de radianes a grados

Este reto está resuelto y explicado paso a paso en Solución del reto de programación: monitor de articulaciones. El paquete educativo adjunto ya admite el parámetro unidad_resumen. Para probarlo, recompila el paquete y ejecuta:

cd ~/ros2_ws
colcon build --symlink-install --packages-select avigtech_xarm_intro
ros2 launch avigtech_xarm_intro monitor_articular.launch.py \
    topic_articular:=/joint_states unidad_resumen:=deg

La conversión solo afecta al texto publicado en /avigtech/xarm/resumen. El mensaje JointState original no cambia.
